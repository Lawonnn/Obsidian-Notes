# Dictionaries
It's  set of peers (key, value)
```
{<exp(key)>: <exp(value)>, ...}
```

>[!warning]
>`key` must be **immutable**

```
<dictionary>.get(<key>, <return_value_if_key_doesnt_exist>)
```
