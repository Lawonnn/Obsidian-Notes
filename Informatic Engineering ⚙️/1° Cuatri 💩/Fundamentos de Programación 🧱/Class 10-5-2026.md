# Objects
Objects help us to create a data type customizable

Example
```python
class Vector:

    def __init__(self, x, y):
        self.x = x
        self.y = y

    def sumar(self, otro):
        return Vector(self.x + otro.x,
                      self.y + otro.y)  

    def restar(self, otro):
        return Vector(self.x - otro.x,
                      self.y - otro.y)  

    def norma(self):
        return (self.x ** 2 + self.y ** 2) ** 0.5

    def distancia(self, q):
        r = self.restar(q)
        return r.norma()
```

The component of a class, in this case `x` and `y`, are called attributes

The function/method  `__init__()` is called every time we use the instance Vector. It's called "constructor" due to it help us to create the attributes of the class

``` python
mario = Vector(25, 32)
vel = Vector(10, 0)

mario = mario.sumar(vel)

koopa = Vector(98, 40)

if mario.distancia(koopa) < 10:
	...
```

``` python

```

``` python

```

```python

```

Operations with Instances:
```python
#Sum instances
<p> + <q>   ➡   <p>.__add__(<q>)

# Sub instance
<p> - <q>   ➡   <p>.__sub__(<q>)

# Multiply instances
<p> * <q>   ➡   <p>.__mul__(<q>)

# Divide instances
<p> / <q>   ➡   <p>.__div__(<q>)

# Eval the instances
<p> == <q>   ➡   <p>.__eq__(<q>)

# Less than
<p> < <q>   ➡   <p>.__lt__(<q>)
```

# Recursion

Example:
$$
n!=n \cdot(n-1)!
$$
