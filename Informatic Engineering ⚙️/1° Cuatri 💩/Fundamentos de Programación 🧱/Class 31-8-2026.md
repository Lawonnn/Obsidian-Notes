# Searching Algorithms
## Linear Search
Linear Search consist in verify value per value if it matches with the value we are looking for
```
>>> def search(password_list, word):
...    for index in range(len(password_list)):
...        if password_list[index] == word:
...            return index
...    return "Word is not in the list"
```

## Binary Search
**Binary Search** is an efficient searching algorithm used to find the position of a target value within a **sorted array or list**.
Instead of checking every element one by one from start to finish (Linear Search), Binary Search works by repeatedly dividing the search interval in half.
### Key Mechanics
1. **Prerequisite:** The input list **must** be sorted.
2. **Logic:**
    - Find the middle element of the array.
    - If the target matches the middle element, you are done.
    - If the target is **smaller** than the middle element, eliminate the right half and repeat the search on the left.
    - If the target is **larger** than the middle element, eliminate the left half and repeat the search on the right.
3. **Time Complexity:** **$\mathcal{O}(\log n)$** — significantly faster than Linear Search **$\mathcal{O}(n)$** for large datasets.
