# Error managing (Exception)
## Types of errors
- Syntax error
- Execution error
- Semantic error

> [!info] Stack Trace
> It's a diagnostic report that shows the exact sequence of function or method calls that a program was executing at the moment and error or crash occurred
## Bubbling up exceptions
```
Global scope ---> main() ---> functionx()
```
To avoid the exception bubbling up, we use:
```
try: ---> Try to do...
	<code>
except [exc_type] as [exc_name]: ---> If something went wrong, do
	<code>
finally: ---> Do it no matters what
	<code>
```

> [!Info] Instruction `raise`
> If we want to show an error we use `raise`
> ```
> raise <exc_type>(<msg>)
> ```
