# Files
A file is a sequence of bytes

## How manage files
1. Open the file
2. Read the file at the first byte
3. Continue with the other byte
4. ....

## Functions
```
<str> ---> open(<file>, <mode> , <enconding type (encoding=...)>) ---> file
```

```
<file> ---> .read(<numbers of characters>) ---> str
```

```
<file> ---> .readline(<numbers of line>)
```

```
<file> ---> .close
```
