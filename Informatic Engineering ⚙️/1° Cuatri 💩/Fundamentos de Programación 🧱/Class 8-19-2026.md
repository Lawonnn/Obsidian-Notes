# Basic Concepts
- **Algorithms**: A set of finite steps that provides a solution of a problem
- **Program**: It's the translator that turns the algorithm in something that computer can understand

# Syntax
- **Expressions**: Are a peace of code that can be evaluate and generate a result
	`suma + cuad(i)`
	- *Literals*: return the same value that we type
		`int(0)`
	- *Variable*: a simple variable
		`n = 5`
	- *Operation*: ``<expression><operator><expression>``
		`n + 1`
- **Instruction**
	- *Allocate*: ``<name> = <expression>``
		`a = 1` ; `b = c`
	- *Function* definition: 
		```
		def \<name>(\<name>, \<name>, ...):
			<instruction>
		```
	- *Return*: `return \<expression>`
	- *Defined* cicle:
		```
		for <name> in <expression (must be iterable)>:
			<instruction>
		```
	- *Import*: `import <name>`
