# Conditions

## Instruction `if`
```
if <expresion>:
	<instructions>
else::
	<instructions>
```

## Bonus track
`assert` instruction:
```
assert <expresion>
```

E. g.
```
assert 2+2==4
```

If the expression is `False` spat out an error (`AssertionError`)

## Conditions Expression
```
<expression> if <expression> else <expression>
```

```
full_name = name + last_name if name and last_name else "N/A"
```

# Cicles
## Definite Cicle
### Instruction `for`
```
for <name> in <expression>:
	<instruction>
```
### Indefinite Cicle
```
while <expression>:
	<instruction>
```

# Sequence
A sequence is an organize set of values
## Strings
```
s = 'python'
```
You can:
- Concatenate
```
<str> + <str> --> <str>
```
- Know their length
```
len(<str>)
```
- Search a value inside
```
<str> in <str> --> <bool>
```

## Tuple
```
t = (8, 'hi', False)
```
You can:
- Concatenate
- Know their length
- Search a value inside

### Lists
```
L = [8, 'hi', False]
```
You can:
- Concatenate
- Know their length
- Search a value inside

> [!warning]
> The only mutable sequence are the lists 


### Properties
- You can access to an element by its position:
```
<expression>[<expression>]
---
dogs[1]
```
- Do slices:
```
<expression[<expression>:<expression>:<expression>]
---
dogs[2:5]
dogs[:3] --> (start in position cero)
dogs[3:] --> (ends at the final position)
dogs[::-1] --> (reverse the order)
```



> [!tip] Format string
> ```
> msg = f"The name {name} have {numbers} of letter"
> ```
