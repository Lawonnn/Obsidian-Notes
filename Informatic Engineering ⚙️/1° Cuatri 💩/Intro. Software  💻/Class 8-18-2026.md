
# Linux
Linux is a kernel system, the core that handle the communication between hardware and software. Although the kernel is a main part of the system, is not enough on its own to make a complete OS. Building an OS, the kernel need to join/merge a variety additional components, such as libraries, tools and utilities 

# What is a OS?
OS is the software that handle the resource of a computer: splits CPU between processes, manage the memory and the disk, talk to the hardware, and provide a graphic interface to use all of these

# What is a kernel?
On the other side, the kernel is the heart of the OS—it's the main part that talks directly to the hardware. You need the kernel, system tools, and a GUI to make an OS usable, which is why people always mention GNU/Linux: Linux gave us the kernel, and the GNU Project supplied the rest of the tools

# Distros
A distribution is a OS built on top of Linux kernel: the kernel plus a packet manager, desktop environment and a pre-installed programs

# History
**UNIX (1969)**: Created in Bell Labs of AT&T by Ken Thompson and Dennis Ritchie, inspire by the Multics project. C language was created just to achieve it.

**GNU (1983)**: Richard Stallman start GNU Project (GNU's Not Unix). Introduce the copyleft concept and GNU General Public License. One of this objetive was build a Unix-like free and he use a lot of tools but never ended up his own kernel

**Linux (1991)**: A personal project by Finnish developer Linus Torvalds. There were already Unix-like systems floating around, but none were free and compatible with Intel 386 processors. Torvalds licensed it under the GPL, and when combined with GNU components, it finally became a complete, free operating system

# UNIX-LIKE
An UNIX-LIKE system is a type of software that works like Unix. Although these system not have to be identic to Unix, they follow some ideas and characteristics like:
- File hierarchy
- Absolute Pathnames
- Relative Pathnames
- Command Interface
- Security and permissions
- POSIX
