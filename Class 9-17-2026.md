# Docker
- Docker only run in Linux system. It run with the system kernel
- It answer the problem of running a specific program without using a virtual machine
- Here we have the concept of `contener`
- 
## Container
It have the code and the dependencies that need docker to run

## Image
The image has the instructions
### Structure
We use a file called *Dockerfile*
```
FROM
WORKDIR
COPY
RUN
EXPOSE
```


# Volumen
A reference of the container to the filesystem

## Commands
Core syntax
```
docker run [flags] <image>
```
In Docker File we can see all pre-made images

```
# To see all active docker containers
docker ps

# To kill a container
docker stop
```
