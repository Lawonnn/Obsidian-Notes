- **/**: Called the root directory; all system information originates from here.
 
- **/bin**: Contains basic executable files used by all users (e.g., `cat`, `ls`).

- **/sbin**: Contains critical system administration commands reserved for the root user (e.g., `sudo`, `reboot`).

- **/boot**: Contains essential files required to boot the system.

- **/etc**: Contains system configuration files (e.g., user profiles, network settings).

- **/home**: Contains the personal home directories for standard users.
 
- **/root**: The home directory for the root user.
 
- **/dev**: Represents hardware devices as files (e.g., keyboards, hard drives).
 
- **/proc**: Contains real-time process and system information.
 
- **/sys**: Contains system and hardware data structured in a modern format.
 
- **/media**: Contains automatically mounted removable media (e.g., USB drives, external hard drives).
 
- **/opt**: Contains optional or third-party software packages not included with the base OS.
 
- **/srv**: Contains data served by the system (e.g., web or FTP servers).
 
- **/tmp**: Holds temporary files.
 
- **/var**: Holds variable data files that change frequently (e.g., logs, cache).
 
- **/usr**: Contains the majority of installed user applications and utilities.
 
- **/lib**: Contains essential shared libraries required for applications to run.
 
- **/lib64**: Contains essential 64-bit shared libraries required for 64-bit applications to run.
 
- **/lost+found**: Contains recovered files following system crashes or disk errors.
