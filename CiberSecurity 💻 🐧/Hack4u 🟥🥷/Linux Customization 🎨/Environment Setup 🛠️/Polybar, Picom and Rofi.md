# Polybar
It's a super customizable taskbar for X windows systems. Polybar stands out with it capacity and flexibility to show various information such as the date, CPU usage, memory and a lot more

# Picom
It's a compositor for X windows systems, meaning it handles how the windows are displayed and manage desktop visual effects, like shadows, transparencies and smooth animation. Picom help to improve the overall aesthetic of the desktop environment

# Rofi
It's a light and customizable app launcher. Rofi lets you quickly search for and launch apps, switch between open windows and even run customizable commands. Its interface is customizable, so you can tweak it however you like
